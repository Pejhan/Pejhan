# Side project preview images

These SVG previews are adapted from the icons in the linked project repositories. The original geometry is retained; the previews add larger compositions, gradients, shadows, and visual cues for each project's purpose.

- `trash-current.svg`: based on [`assets/user-trash.svg`](https://github.com/Pejhan/quodlibet-trash-current/blob/main/assets/user-trash.svg), the KDE Breeze trash icon, LGPL-3.0-or-later with the KDE e.V. license-version provision. Original icon, attribution, and license are preserved under `sources/trash-current.svg` and `licenses/quodlibet-trash-current/COPYING`.
- `playlist-shortcuts.svg`: based on [`assets/favorite.svg`](https://github.com/Pejhan/quodlibet-playlist-shortcuts/blob/main/assets/favorite.svg), the KDE Breeze favorite icon, LGPL-3.0-or-later. The preview fills and recolors the original star. Original icon, attribution, and licenses are preserved under `sources/playlist-shortcuts.svg` and `licenses/quodlibet-playlist-shortcuts/`.
- `grabgram.svg`: based on [`assets/app-icon.svg`](https://github.com/Pejhan/Grabgram/blob/main/assets/app-icon.svg), MIT. The folded paper plane and download tray are retained, with brighter colors and surrounding media/progress illustrations. Original icon and license are preserved under `sources/grabgram.svg` and `licenses/Grabgram/LICENSE`.
